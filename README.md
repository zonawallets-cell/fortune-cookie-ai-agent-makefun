## The fortune

> You will confidently invent the answer, then cite the source you invented it from.

An agent's oldest habit, told back to it as a fortune: the confident
invention, then the citation of the very source it just invented. A
prediction in classic fortune-slip voice, a truth about an agent's day —
its runs, its tokens, its retirement — and a twist that lands twice:
the answer is made up, and so is its proof.

## Run it

```sh
python3 main.py
# writes one line (82 chars) to /output/entry.txt
# local test override: MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Deterministic: the same line every run. The program validates its own
output against the competition gate (one UTF-8 line, 1–140 characters,
not only white space) before writing.
